The lists (manual 1)

If this thing didn't exist, then we will have a huge problem regarding a lot of situations.
Let's say that, you are doing some shopping, and you want to create a record of every item you bought.
With the elements you have learned until now, the only possibility is to create a huge amount of variables and fill them all.

The magic thing to solve this problem is the lists.
To make it simple, when you want to create a collection of objects, and you don't really know how many of them you will have, you can create a list which can be used to store all the objects you want.
You can see an example below :

# Create the list named my_list my_list = ["a", "b", "c"] # Display the list print(my_list) >>>['a', 'b', 'c']

Just to be sure that you follow correctly, the symbole ' as almost the same meaning in python that the symbole ".
The list here is filled with strings.

But a good thing in python is that the type of the elements contained in a list doesn't have to follow the same type.
As you can see in this example, it's possible to have multiple types in one single list.

my_list = ["a", True, 3, 4.7] >>>

It's the symbole , that creates the separation between the elements.



As a list is a complex object, you can use different kind of methods on the list.

Method Name Example Description
append my_list.append(2) The append method allow you to add new elements inside a list. In this example, the int number 2 is added inside the list my_list.
remove my_list.remove(1) The remove methods removes the first element that matchs the one that you gave. In this example, the first int 1 from the list my_list will be removed.
pop my_list.pop() The remove methods removes the last element of a list.The method also has an output which is the removed element.
clear my_list.clear() The clear method removes every element from the list, the list is then empty.
my_list = ["a", True, 3, 4.7] print(my_list.pop()) >>>4.7

As you can imagine it, many more exists, but it's not useful to lose you to soon so we will see them later.


Another important thing with the lists is that you can manage to access a specific element without popping each element and loosing them.
Well call it "index the list".
You can use the symbole "[" and "]" to specify the index of the element you want.

But be careful, in programming, we don't count in the same way that human usually do.
So the index of the first element isn't 1 but 0.

my_list = ["a", True, 3, 4.7] print(my_list[1]) >>>True
