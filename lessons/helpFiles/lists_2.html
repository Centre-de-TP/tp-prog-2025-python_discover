Here the goal is to add methods and functions so the lists are even easier to use for you.
But first you need to understand something about one most basic structure you learned.

I'm here talking about the string.
Don't you find the structure similar to the lists ?
Did you never ask yourself if the two structures were the same ?
The answer is located far inside the behaviour of a computer but basically a string is a list of characters.
As well, since a computer understand only binary operation like True or False deep inside, a character is a number in a range of characters we call the ASCII Table.


Now that you understood everything here, let's introduce the functions :

Function Name Example Description
len len(my_list) The len function calculates the size of the list (size meaning the number of element).
len len(my_string) The len function calculates the size of the string (size meaning the number of characters).
Method Name Example Description
join my_separator_string.join(my_list_of_string) The join method combine all the strings inside the list given in argument separating each by the string it's called on.


Now that you get those functions, some functions may be useful as well for playing with characters.
If you remember the lesson about the cast function in python, you'll probably see a similarity.

Function Name Example Description
ord ord("A") The ord function takes a string of length equal to one, and it returns the ASCII value of it.
chr chr(65) The ord function takes an int, and it returns the character with the corresponding ASCII value.
