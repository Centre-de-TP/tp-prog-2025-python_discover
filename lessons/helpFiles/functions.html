The Methods

Didn't you ask yourself about what exactly is a function ?

If you remember well what you have learned since the beginning, you should remember that you started the journey with something which we call the function "print".
But what exactly is a function ?

To make it simple, you can imagine a line of production in the real world.
I like to call it a factory.
It may need raw materials, and it will create a final product with it.
But this same product can be used in another factory to create even more complex products.

The "print" was an example of a function that takes on or multiple object of any type at the start of the process and creates no real output, but you can see a result action.
As a more explicit example, let's take the function "input".
If you try to describe how it works it would look like that :

response = input("my question") print(response) >>>my response
Element Factory Comparison Description
input The name of the factory Once a function is defined, you add a tag on it like for the variables so you can get them back and use it.
( The left entry door of the factory This symbole is the mark for the starting point of the arguments (the raw material to give to the function).
"my question" One of the factory raw material These that we call arguments are the objects that a function needs to work and do it staff.
) The right door of the factory This symbole is the mark for the ending point of the arguments (the raw material to give to the function).
my response The final product of the factory Most of the function can give an output, it the resulting object created by the function.

Before that you ask it, yes a function can need multiple arguments.
In those cases, we need to use the symbole "," to create a separation between them.



Imagine now that you are writing code and some action are being written multiple times.
Another interesting thing in programing is that you can also create your own functions.
To do that we created another keyword called "def".
This keyword will help you to define a function behaviour and once it is created you can use it as whenever you want.

def my_function(argument1, argument2) : print(argument1 + argument2) return argument1 + argument2 my_function(1, 2) >>>3

If the syntax reminds you something, it could be because of the condition checkers.
Here as well it's very important not to forget the space before the function action(s).
This defines the scope of activity of the function (what action is in the function, which one is outside).

Another thing about this example is that the tag assigned to the arguments (here argument1 and argument2) can be used only inside the function.
It will make no sens to call an element with the name it has inside a factory when you are home, your family will not understand.
Here it's the same, it makes no sens to use "argument1" outside the function "my_function".
